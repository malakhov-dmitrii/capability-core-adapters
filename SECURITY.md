# Security

This repository contains documentation, templates, and optional agent skills.

## Agent skill safety

Skills are instruction files. Treat third-party skills as code-adjacent assets:

- read them before enabling;
- avoid granting broad tool permissions by default;
- prefer project-local installation when testing;
- keep secrets out of examples and templates.

## Reporting

If you find a security issue in the skill instructions or templates, open a
private report through GitHub Security Advisories when available, or file an
issue without including sensitive exploit details.
